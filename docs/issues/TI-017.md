# TI-017 — Pin Rust 1.97.1 across build and release surfaces

## Required outcome and acceptance

Move TranscribeIt's minimum and active Rust toolchain from 1.96 to the latest
stable point release, Rust 1.97.1. Use the exact point release so local builds,
Cargo's declared minimum, CI checks, release builds, and tag guards cannot
silently resolve to different patch versions. Do not select Rust 1.98 before it
reaches stable, and preserve historical benchmark toolchain strings as recorded
evidence.

Update Cargo metadata, the repository toolchain file, CI and release workflows,
prerequisites, architecture guidance, and the changelog together. Acceptance
requires an unchanged locked dependency graph, formatting, all-target tests,
exact strict Clippy, a locked optimized build, workflow validation when the
validator is available, and the default repository gate. Cross-platform release
jobs remain authoritative only after the changes are published and GitHub runs
them.

## Outcome and validation

Resolved by selecting exact Rust 1.97.1 across Cargo's minimum-version metadata,
the rustup override, both CI jobs, and both release-workflow installation sites.
README prerequisites, architecture guidance, and the unreleased changelog now
state the same requirement. Historical benchmark environment strings were left
unchanged.

Rust 1.97.1 was the latest stable point release on 2026-08-17; Rust 1.98 was
still beta with its stable release scheduled for 2026-08-20. The exact point
release was selected because the Rust release team documents an LLVM
miscompilation fix in 1.97.1.

Validation completed on 2026-08-17:

- the active toolchain reported `rustc 1.97.1` and `cargo 1.97.1` on Apple
  Silicon;
- `Cargo.lock` retained SHA-256
  `eb623c5e80115fdd13645eb96998429cb919650964e1fcdce9560fa5ab374e88`
  before and after the change;
- `actionlint .github/workflows/*.yml` passed;
- `./scripts/check.sh` passed under Rust 1.97.1 with 108 unit tests, two CLI
  security integration tests, exact strict Clippy, formatting, policy/hook
  tests, module-size, skills, issue-registry, corpus, and benchmark-matrix
  validation;
- `cargo build --release --locked` passed and the optimized binary reported
  version 2.0.0;
- `cargo audit --deny warnings` still reports only the pre-existing
  `RUSTSEC-2026-0253` warning through `aws-sdk-s3` and `lru`, tracked separately
  by TI-011; the toolchain change did not alter that dependency graph;
- Linux, Windows, Intel macOS, and Apple Silicon release jobs remain pending
  GitHub evidence because this working tree has not been committed or pushed.
