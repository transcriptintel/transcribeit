# TI-005 — Decide whether to package llama.cpp Qwen3-ASR support

## Required outcome and acceptance

Turn the existing exploratory OpenAI-compatible `llama-server` path into a clear
product decision. If packaging proceeds, define server discovery or lifecycle,
startup/readiness and shutdown behavior, default model selection, artifact
ownership, timeout and cleanup behavior, provider metadata, and a timestamp or
alignment contract. If it remains external-only, document that boundary and the
supported generic base-URL configuration without implying managed lifecycle.

Acceptance requires reproducible 0.6B and 1.7B evidence on the representative
corpus, explicit memory and warm/cold latency observations, and a decision that
does not compromise the standalone-binary expectation accidentally.
