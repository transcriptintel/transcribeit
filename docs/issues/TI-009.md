# TI-009 — Run and record the live provider smoke matrix

## Required outcome and acceptance

Execute the repaired OpenAI, DashScope/Qwen, Gemini, Deepgram, NVIDIA Riva, and
Azure smoke paths for every configured provider account. Reuse existing ignored
credentials, request missing keys through the established workflow, and record
only status, latency, model/endpoint classification, date, and a sanitized error
category. Response bodies, transcript text, request identifiers, signed URLs,
and credential values must not be printed or retained.

Acceptance requires a successful or explicitly classified result per configured
provider, commands that fail on HTTP errors, and clear separation between an
unconfigured/skipped provider and a passing provider. Live evidence applies only
to the tested account, region, model revision, request shape, and fixture.

## Outcome and validation

All six requested provider accounts were configured and passed one live CLI
smoke on 2026-08-06. The run used clean commit
`e136b3b28c67df4faf871c8bcbdf1bae84b25d17` and the pinned 12.64-second
`fleurs-en-us-traffic-flow-clean` fixture (SHA-256
`3e76cc5728bfd7c24f1039b5c9a47e8d79c7f225605862e977833a4f79249bff`).
Retries and segmentation were disabled, the timeout was 300 seconds, and each
provider received one text-output request through TranscribeIt's production CLI.

The transcript-free record is
[`2026-08-06-ti-009-live-provider-smoke.sanitized.json`](../../benchmarks/results/2026-08-06-ti-009-live-provider-smoke.sanitized.json).

Qwen's staged object and Gemini's uploaded file were both reported deleted by
their normalized provider metadata. No provider was skipped or unconfigured.
A separate local synthetic HTTP 401 probe exercised the same compatible CLI path
with retries disabled and confirmed a nonzero process exit classified as
`authentication`; its response body was discarded.

Credential values were loaded only from the ignored mode-`0600` environment
file. The runner captured and discarded stdout, stderr, and provider response
bodies. Tracked evidence contains no transcript text, request identifiers,
signed URLs, endpoint hostnames, local paths, function identifiers, deployment
names, or credential values. After sanitization, all twelve temporary transcript
and manifest files plus the runner were deleted, and the exact evaluation path
was verified absent, reclaiming 102,400 allocated bytes. No model was downloaded.
