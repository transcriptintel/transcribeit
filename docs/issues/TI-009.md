# TI-009 — Run and record the live provider smoke matrix

## Required outcome and acceptance

Execute the repaired OpenAI, DashScope/Qwen, Gemini, Deepgram, NVIDIA Riva, and
Azure smoke paths for every configured provider account. Reuse existing ignored
credentials, request missing keys through the established workflow, and record
only status, latency, model/endpoint classification, date, and a sanitized error
category. Response bodies, transcript text, request identifiers, signed URLs,
and credential values must not be printed or retained.

Acceptance requires a successful or explicitly classified result per configured
provider, commands that fail on HTTP errors, and clear separation between an
unconfigured/skipped provider and a passing provider. Live evidence applies only
to the tested account, region, model revision, request shape, and fixture.
