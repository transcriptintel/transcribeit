# TI-002 — P2 provider hardening, portability, and benchmark reproducibility

## Required outcome and acceptance

Complete the follow-up hardening pass: restrict local FFmpeg protocols, preserve
Riva speaker transitions, bound HTTP and SSE bodies, make Gemini cache updates
locked and recoverable, persist transcripts before optional analysis, validate
subtitle timing, surface FFmpeg probe failures, finish Sherpa bootstrap
portability, add all-feature CI, repair provider smoke tasks, create private
outputs, and establish tracked benchmark evidence.

## Outcome and validation

All twelve P2 contracts were implemented with focused negative and concurrency
coverage. The tracked benchmark protocol now includes machine/tool/commit data,
fixture hashes, exact commands, classification, and sanitization. The first
reference record contains three successful `gpt-transcribe` runs and preserves
the live `diarized_json` rejection as compatibility evidence rather than a
successful diarized result.

Default and all-feature Rust tests and strict Clippy passed, as did workflow,
shell, Taskfile, JSON, sanitizer, Markdown-link, and whitespace validation. No
tracked result contains transcript text, request IDs, credentials, signed URLs,
or absolute local paths.
