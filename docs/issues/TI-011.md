# TI-011 — Remove the transitive lru unsoundness advisory

## Required outcome and acceptance

Resolve RUSTSEC-2026-0253, which currently applies to `lru 0.16.4` through
`aws-sdk-s3`. The maintained AWS SDK release still constrains `lru` to the
affected 0.16 line, while RustSec identifies 0.18.2 as the first patched
release. Do not force an incompatible transitive version or suppress the
advisory in the repository audit command.

Acceptance requires a Renovate dependency update to an AWS SDK release that
permits a patched `lru`, no affected `lru` package in `cargo tree`, and a clean
`cargo audit --deny warnings`. Until then, the scheduled Node 24 RustSec action
must retain permission to create a deduplicated GitHub issue for the advisory;
push and pull-request runs must retain permission to publish their audit check.

The observed advisory requires a key whose `Drop` implementation panics during
`LruCache::pop()` while unwinding is caught. No such use has been identified in
TranscribeIt, but that narrow trigger does not make the dependency sound and is
not grounds for closing this issue.
