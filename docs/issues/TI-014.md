# TI-014 — Benchmark Apple Speech on the representative corpus

## Required outcome and acceptance

Run `apple-speech` through the tracked representative corpus before the provider
is included in a release baseline. Measure transcript accuracy, term retention,
native timing source/reliability and output shape, long-form behavior, wall time,
RTF, and peak process RSS. Record that Apple Speech does not expose speaker
labels or word timestamps, so DER and word-timestamp measurements are unsupported
rather than zero. AMI's overlapping multi-speaker reference must likewise report
ordinary serialized WER and boundary MAE as unsupported; do not turn ambiguous
alignment into a score.
For every fixture, also record whether AVAudioFile accepted the original media
or TranscribeIt's temporary WAV fallback was required.

Acceptance requires a clean-commit benchmark record with macOS version/build,
architecture, resolved locale, Apple Intelligence availability, locale-asset
installation request state, cold/warm classification, fixture hashes, exact
commands, and sanitized transcript-free artifacts. Compare the result with the
current local whisper.cpp baseline without treating one host or one OS-managed
model revision as a universal ranking.

Apple owns and shares the locale asset. Record that lifecycle boundary and do
not delete system speech caches or the shared public corpus. The harness removes
each transcript-bearing attempt directory after its hashes and in-memory metrics
are captured. Separately remove only the evaluation-owned large-v3 model
directory, verify that exact root is absent, and record the observed reclaimed
bytes. Remove the ignored run directory only after the sanitized result is copied
and validated.

## Harness preparation

The tracked
[`ti-014-apple-large-v3.yaml`](../../benchmarks/matrices/ti-014-apple-large-v3.yaml)
matrix defines the clean representative-corpus run without claiming that it has
already completed. It pairs Apple Speech with the pinned local whisper.cpp
large-v3 artifact for all four corpus fixtures and three repetitions, producing
24 attempts. Concurrency is one, and `fixture-repetition-entry` ordering
deterministically alternates Apple and local attempts within each fixture and
repetition. Apple receives the explicit `en-US` locale while local whisper.cpp
receives the `en` language hint.

The harness now distinguishes Apple Speech from hosted providers without passing
it a model argument, while local whisper.cpp continues to receive `--model`.
Reference scoring computes WER for the three non-overlapping reviewed transcripts
and term recall for all fixtures. AMI WER and boundary timing explicitly report
`unsupported_overlapping_reference`; the other fixtures have no timestamp
reference, so this matrix observes native timing metadata and shape without
claiming a reference-scored boundary MAE. Raw transcript and manifest outputs are
hashed and deleted before publication by default. On Darwin, the matrix requests
peak process RSS through `/usr/bin/time -l`; the result also records macOS
version/build, Swift, the resolved Apple locale, Apple Intelligence and on-device
state, locale-asset request state, input preprocessing, processing time, RTF, and
output shape through strict allowlists.

The Apple asset is declared `system_managed`; cleanup must never target it. The
large-v3 artifact is declared `evaluation_download` with its pinned revision,
byte count, and SHA-256. Publication requires validated, run-bound
`transcribeit.downloaded-model-cleanup.v1` evidence and independently verifies
that the bound evaluation root is absent; byte counts remain operator-observed.
The live clean-commit run, sanitized result review, documentation of observed
metrics, and TI-014 resolution remain pending.

## Exploratory evidence

The 2026-08-17 [sanitized long-form comparison](../../benchmarks/results/2026-08-17-ti-014-apple-vs-large-v3-exploratory.sanitized.json)
used one private 3,234.752-second Japanese M4A and two sequential repetitions of
Apple Speech and local whisper.cpp large-v3. Apple directly accepted the M4A and
had an 18.81-second median wall time; local converted to WAV and had a
615.37-second median. Both outputs were deterministic, and normalized transcript
bigram/trigram overlap was strong, but no reviewed reference exists, so no
accuracy conclusion is supported.

This evidence is intentionally not a TI-014 resolution or release baseline: the
worktree was dirty, the fixture is outside the representative corpus, and the
Apple asset was warm. The evaluation-owned large-v3 download and raw outputs
were deleted after evidence capture, removing 3,096,993,151 logical bytes and
leaving the exact evaluation root absent.
